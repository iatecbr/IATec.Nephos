# DSA-125 — nph-collapsible: start, tag and end slots on the row trigger

## Goal
On 2026-11-19 the design owner approved bringing the slots of the nph-accordion item to the nph-collapsible,
hidden by default: media at the start, a tag next to the title and a status at the end. On 2026-11-26 she
chose where: only the row trigger (`tipo=linha`, flush and card). The button trigger and the "read more"
preview keep only text and arrow. In the market, media at the start and content at the end appear only on
full-width triggers (Fluent UI AccordionHeader icon, Mantine Accordion icon, Ant Design Collapse extra).

## What changed in the tokens (on v/5.0.0 in the same push as this task)
- `collapsible/tag-gap` → `space/inline` (8): the gap between the title and the tag, as
  `accordion/tag-gap`. Generated `--nph-collapsible-tag-gap`.
- Already on v/5.0.0 since 2026-11-26 01:21 (`b043d38f`): `collapsible/title-gap` → `core/space/50` (2).

## What Figma draws (set `6006:2250`, page "NPH — Collapsible", 2026-11-26)
- Three new boolean properties, off by default: `início`, `tag`, `fim`.
- In the 96 variants of `tipo=linha`: `início` (an instance of `nph-accordion / início`, icon type, size
  by the trigger size) before the title column; the title inside a `linha do título` row with the tag
  (`nph-badge`, primary light) at `collapsible/tag-gap`; `fim` (a `nph-badge` status, success light) after
  the title column, before the end indicator.
- The title hugs its text in that row, as in the accordion item; the description keeps its width.
- `tipo=botao` and `tipo=previa` are unchanged.

## What changes in the code
- `src/components/nph-collapsible/nph-collapsible.ts`: the row trigger renders three named slots, for
  example `start`, `tag` and `end`, each shown only when it has content (the same contract as the
  nph-accordion item). The trigger stays the only interactive element: anything clickable goes outside it,
  so the end slot is a status, never a button (React Aria Disclosure, Mantine Accordion, MUI Accordion).
- CSS: the title and the tag share a row with `--nph-collapsible-tag-gap`; the start content sits before
  the title column and the end content before the end indicator, all centered on the trigger.
- The button and preview types ignore the slots.

## How it is proved
- Stories in light and dark: the row trigger, flush and card, with the avatar at the start, the tag "Novo"
  and the status "Concluído"; and without them, unchanged.
- `npm test` for nph-collapsible.

## What this task does not do
It does not create or change a token. It does not change Figma. It does not make the nph-accordion item an
instance of the nph-collapsible.

# PF-15 — shadow and elevation in the generator, with PF-16 and PF-05

## Goal
The 24 `core/shadow-*` primitives, the 11 effect styles, the motion that was missing and
the spinner loop are on the default branch. You can tell they exist when
`npm run build:tokens` on `v/3.0.0` emits the shadow and the generated CSS contains it.

## Related IDs
**PF-16** — `core/duration/400` and `core/easing/linear`. **PF-05** — the 800 ms
duration of the spinner loop, which went in as `core/duration/loop` and the sixth
semantic role `motion/loop-duration` / `motion/loop-easing`.

The three traveled in the same PR by a recorded decision of the sequence. **They have
no task of their own**: duplicating the ID would create two sources for a single piece
of work, which is the error this structure exists to prevent.

# DSA-108 — Six editor icons in the `nph-icon` core

## Goal
The `nph-rich-text-editor` toolbar (DSA-105) uses nine icons that were not in the Figma `nph-icon`. In code, `bold`, `italic` and `underline` are already in the core (DSA-23 D1). The other six enter the core here, with `light` and `solid`, so the editor can show them: `rotate-left` (undo), `strikethrough`, `list-ul` (bulleted list), `list-ol` (numbered list), `block-quote` (quote) and `text-slash` (clear formatting).

## Where the decision is
In the evidence of the `foundation-decision` gate: `docs/operacao/evidencias/DSA-108/foundation-decision-2026-11-22.md`. There is no need to open Figma.

## What changes
### Icon map
In `src/components/nph-icon/nph-icon.icons.ts`: the six names in `NPH_ICON_NAMES` and in `GLYPHS`, each with its `light` and `solid` artwork from Font Awesome Pro, by a deep import as the others (`faRotateLeft`, `faStrikethrough`, `faListUl`, `faListOl`, `faBlockQuote`, `faTextSlash`). If the installed Font Awesome version lacks one of them, stop and say which: the name stays out and the editor keeps a gap there, not another icon.

### Core list
In `design.md`, `icones_nucleo.acao.icones`: the six names, in the alphabetical order of the list. The block says "If the component needs an icon that is not on the list, it is a gap: ask before adding"; this task is that answer.

### Texts that list the core
The `nph-icon` tests, demo and docs story that read or list the core names follow the map (`nph-icon.test.ts`, `nph-icon.demo.ts`, `nph-icon.docs.stories.ts`), and `fichas/nph-icon.md` where it names the categories. No count of icons is written (the living texts carry no count).

## How it is proved
**`foundation-decision`** — passed. **`review-and-merge`** — the map compiles with the closed matrix (`satisfies`), each new name renders in `light` and `solid`, the proof commands in `docs/operacao/component-handoff.md` exit 0, and the work is merged into `v/5.0.0`.

## What this task does not do
It does not change a token. It does not change the `nph-rich-text-editor` (DSA-105, which waits for this task). It does not change Figma: the design side adds the nine icons to the Figma `nph-icon` (`248:143`), in Classic Light, and swaps the skeletons of the editor toolbar, apart from this task.

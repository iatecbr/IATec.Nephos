# DSA-127 — nph-skeleton line box and nph-switch label drop

## Goal
Two answers of 2026-11-26 sit in tasks that are already done and ask for code: DSA-26 D1 (the line
skeleton gets a box as tall as the text line, with the bar centered) and DSA-27 D5 (the switch label
drops 2 px in the default size). The same day the design owner named both values as tokens. This task
carries the code change of both.

## What changed in the tokens (on v/5.0.0 since 2026-11-26)
- `skeleton/line-box-height` → `core/line-height/200` (20). Generated `--nph-skeleton-line-box-height`.
- `switch/label-offset` → `core/space/50` (2), a declared exception to the half step in `design.md`.
  Generated `--nph-switch-label-offset`.
- `skeleton/line-height` (16) stays the height of the bar.

## What Figma draws (2026-11-26)
- nph-skeleton `forma=linha` (`1578:31`): an auto layout box of `skeleton/line-box-height` with no fill;
  inside, the bar `barra` of `skeleton/line-height`, `radius/inner`, `skeleton/background`, full width,
  centered. A usage that stands for `text/body-sm` keeps a 16 px box.
- nph-switch (`1548:56`), the 12 variants of `tamanho=padrão`: the label sits in a `recuo do rótulo` frame
  with `switch/label-offset` on top; the track stays at the top. The small size is unchanged.

## What changes in the code
- `src/components/nph-skeleton/nph-skeleton.css`, `shape='line'`: the host block size reads
  `--nph-skeleton-line-box-height`; the visible bar (a pseudo element or an inner part) reads
  `--nph-skeleton-line-height`, `--nph-radius-inner` and `--nph-skeleton-background`, centered in the box.
  The consumer can still set a smaller box for small text.
- `src/components/nph-switch/nph-switch.css`, default size: the `.text` label gets a top margin of
  `--nph-switch-label-offset`; `.control` keeps `align-items: flex-start`, so a wrapped label keeps the
  track on the first line.

## How it is proved
- Stories in light and dark: a skeleton line next to a 20 px text line, centered; a switch with a one line
  and a two line label in the default size, the first line centered on the track; the small size unchanged.
- `npm test` for nph-skeleton and nph-switch.

## What this task does not do
It does not create or change a token. It does not change Figma. It does not change the block and avatar
shapes of the skeleton, nor the small switch.

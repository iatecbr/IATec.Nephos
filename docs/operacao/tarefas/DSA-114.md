# DSA-114 — `nph-carousel`: a softer non-current indicator dot

## Goal
Before this task, the non-current dot of the `nph-carousel` indicators (`carousel/indicator-background`) pointed to `color/subtle-foreground`: `#737373` in light, `#ababab` in dark. The design owner wanted a softer dot that still passes 3:1 (WCAG 1.4.11, non-text contrast). She chose option 3 of the Figma preview `8121:23528`. The token is on `v/5.0.0` with the token commit of this task. What is left is the test and the spec.

## Where the decision is
In the evidence of the `foundation-decision` gate: `docs/operacao/evidencias/DSA-114/foundation-decision-2026-11-23.md`. It carries the three options, the contrast table and the sources. There is no need to open Figma.

## What changed in the tokens (token commit, already on `v/5.0.0`)
- **New semantic, `color/marker`** (token rule T9, no new value in the core): today `core/slate/400` (`#6f7d91`) in both schemes. It was written on `core/neutral/400` (`#8f8f8f`) in light and `core/surface/400` (`#6f7782`) in dark, before the slate swap of 2026-11-24 (commit `f9196052`). Its function is the non-current position marker, a non-text mark. Its `use` and `nao_use` are in `design.md`.
- **`carousel/indicator-background`** points to `color/marker` instead of `color/subtle-foreground`. In the generated CSS: `--nph-carousel-indicator-background: var(--nph-color-marker);`.
- **`carousel/indicator-background-current`** does not change: `color/primary-border`.
- **`color/subtle-foreground`** no longer names the carousel dot in its `use` in `design.md`. Its value does not change.
- The component CSS does not change: `nph-carousel.css` already reads `--nph-carousel-indicator-background`.

## Contrast (WCAG formula)
Measured again on the current token, `color/marker` = `core/slate/400` (`#6f7d91`) in both schemes:

| Surface | Light | Dark |
|---|---|---|
| `color/background` | 4.18:1 | 4.09:1 |
| `color/card` | 4.18:1 | 3.37:1 |
| `color/muted` | 3.93:1 | 2.59:1 |
| `color/accent`, the target background in hover | 3.93:1 | 1.93:1 |

Over `color/background` and `color/card` the dot passes 3:1 in both schemes. Over `color/muted` and, in hover, over `color/accent` it passes in light and is below 3:1 in dark. The design owner chose option 3 on the figures of the preview (dark: 3.53:1 over `color/card`, 2.81:1 over `color/muted`, 2.18:1 over `color/accent`); the dark figures above are lower, and they stay: D1 was answered on 2026-11-26 (section "Decision answered on 2026-11-26"). The gate records what was decided, and the figures here are the ones of the token on `v/5.0.0` today. The current dot (`color/primary-border`) does not change.

## What the code owner does
1. **Token contract test.** `src/components/nph-carousel/nph-carousel.test.ts`, two places:
   - "the tokens point where the contract says": the line for `--nph-carousel-indicator-background` expects `var(--nph-color-subtle-foreground)`. It now expects `var(--nph-color-marker)`. Until then, this assertion fails and `npm test` is red on `v/5.0.0` (the repository has no CI that blocks on it), so do this item first.
   - "design.md names the semantic tokens the carousel tokens alias": the match on `color\/subtle-foreground` becomes `color\/marker`. It still passes today only because `design.md` names `color/subtle-foreground` for other pieces.
   The list of fourteen carousel tokens and the semantic tokens the CSS reads stay the same.
2. **Spec.** `fichas/nph-carousel.md`, two places, with the figures of the table above:
   - the `contrast` line of the accessibility block: the non-current indicator passes 3:1 over `color/background` and `color/card`, and is below 3:1 over `color/muted` and in hover over `color/accent`. The hover background of its target stays, as it is today (see "What this task does not do").
   - the "Contrast" row of the summary table ("The indicators and the arrow icon pass 3:1"): the same correction.
   The current indicator, the arrow icon and the counter do not change.
3. **Metadata.** Regenerate `src/shared/metadata/nph-carousel.json` from the spec with `node scripts/verificar-operacao.mjs --gerar-metadata`; never edit it by hand. Its `contrast` line follows the spec.
4. **Stories.** The "Contrast" row of the nph-carousel docs block says "The indicators and the arrow icon pass 3:1", in the three languages: `.storybook/i18n/en.json`, `es.json` and `pt-BR.json`, line 16735 in each. Correct it in the three languages with the same sentence as the `contrast` line of the spec (item 2).

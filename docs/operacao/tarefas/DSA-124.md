# DSA-124 — nph-select: the selected and active option, and the radius pair

## Goal
In the approval round of the nph-rich-option (2026-11-18) the design owner chose two looks for the option
of the select list: the selected option keeps only the check, without background (item 10), and the option
active by keyboard draws the focus of the list items, a 1 px border plus a 4 px halo outside (item 9). She
left the radius pair for later (item 11). On 2026-11-26 she kept the list at 8 px and the option at 4 px,
the pair of today, because every layer anchored to a trigger now has one 8 px radius (DSA-123).

## What Figma draws (set `1357:136`, page "NPH — Select", read on 2026-11-26)
| State | Figma | Code today (`src/components/nph-option/nph-option.css`) |
|---|---|---|
| Selected, marker check | no background; the check in `select/option-marker` | `:host(:not([marker='checkbox']):state(selected))`, line 129, paints `color/primary-surface` |
| Selected, marker checkbox | no background (already) | no background (P96) |
| Active (`state=ativa`, 8 variants) | the hover look plus a 1 px border (`select/option-focus-border`, `-width`, `-radius`) and a 4 px halo outside (`select/option-focus-halo`, `-width`, `-radius`) | `:host(:state(active))`, line 120, paints only the hover look |
| Corner of the option | `select/option-radius` → `radius/inner` (4) | `radius/inner` (line 32) |
| Corner of the list `1357:137` | `select/panel-radius` → `radius/overlay-anchored` (8) | `radius/container` (8), changed by DSA-123 |

## What changes in the code
- Selected with the check marker: no background. `select/option-background-selected` stops being read by
  the plain option; the rich option keeps what DSA-91 says.
- Active: keep the hover look and add the focus ring of the list items: border `--nph-select-option-focus-border`
  at `--nph-select-option-focus-border-width`, corner `--nph-select-option-focus-border-radius` (5), and a halo
  `--nph-select-option-focus-halo` at `--nph-select-option-focus-halo-width` outside, corner
  `--nph-select-option-focus-halo-radius` (9). Same pattern as the nph-rich-option (DSA-91).
- Selected and active together: the ring over the selected look (Figma composes them with a hidden hover layer
  on the selected variants).
- The list keeps 4 px of breathing room; at the first and last option the halo touches the edge of the list and
  loses 1 px, because the list clips what overflows (as today).

## How it is proved
- Stories in light and dark: a list with one selected option (check, no background) and one active option
  (border and halo); keyboard arrows move the ring.
- `npm test` for nph-option and nph-select.

## What this task does not do
It does not create or change a token. It does not change Figma. The list radius token is DSA-123.

# DSA-103 — Remove `notification/stack-gap`

## Goal
After DSA-100, the gap between toasts is `toast-region/gap`, read by the `nph-toast-region`. `notification/stack-gap` then has no reader: it leaves the tokens, and every text that still names it changes in the same work.

## Where the decision is
In the evidence of the `foundation-decision` gate: `docs/operacao/evidencias/DSA-103/foundation-decision-2026-11-22.md`. There is no need to open Figma.

## What changes
### Token
In `src/tokens/source/semantic.tokens.json`, remove `notification.stack-gap` and lower `expectedCount` by one. Regenerate `src/tokens/generated/tokens.css` (the line `--nph-notification-stack-gap`). No other token changes. `space/stack-snug` stays: other tokens read it.

### Files that name it today (read on `v/5.0.0`, 2026-11-22)
DSA-100 already moves some of them to the region. Whatever still names `notification/stack-gap` after DSA-100 changes here:

| File | What it has today |
|---|---|
| `src/components/nph-notification/nph-notification.test.ts`, test "every notification token of the contract is read by the CSS, but the gap of the region…" | the list `['--nph-notification-stack-gap']`; it becomes an empty list, and the title loses "but the gap of the region" |
| `src/components/nph-notification/nph-notification.demo.ts` | the `toastRegion` helper and its comments (`gap: var(--nph-notification-stack-gap)`) |
| `fichas/nph-notification.md` | the `region` token line, the `ai_hints` line, the region example, the "Put `notification/stack-gap`" line, the token table row and the closing lines |
| `src/shared/metadata/nph-notification.json` | `region` and the `ai_hints` line, as the sheet |
| `.storybook/i18n/en.json`, `es.json`, `pt-BR.json` | the region story texts (today lines 8648 and 11893) |

Before closing, search the repository for `notification/stack-gap` and `--nph-notification-stack-gap`. Leave as they are: `docs/operacao/evidencias/` (evidence is history), `docs/validation/angular-rc2/validation.md` (an old validation) and `docs/decisoes-tecnicas.md` P108; add to P108 a new note that names DSA-103, and the old text stays as history.

## How it is proved
**`foundation-decision`** — passed. **`review-and-merge`** — the token, the generated CSS, the test, the sheet, the metadata, the demo and the Storybook texts change together; `build:tokens` and the whole test suite pass; the proof commands in `docs/operacao/component-handoff.md` exit 0; and the work is merged into `v/5.0.0`.

## What this task does not do
It does not change `toast-region/gap` or any other token value. It does not create a token. It does not change Figma: the design side removes the variable `notification/stack-gap` (`VariableID:4243:228`) after this task is merged.

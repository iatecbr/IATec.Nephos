# Illustrations

Raster illustrations used by Nephos components, exported from the Figma
`DS-IA-NEPHOS 5.0` file. They are assets, not tokens.

- One file per color scheme: the light one has no suffix and the dark one ends
  in `-dark`.
- The name says the piece and the situation: `<piece>-<situation>.png`, without
  the `nph-` prefix.
- The component shows the light file with `scheme/is-light` and the dark one
  with `scheme/is-dark` (`design.md`, `tokens_scheme`).
- An illustration is decorative: the component hides it from the screen reader
  with `aria-hidden`, and the message stays in the text.

| File | Piece | Scheme |
|---|---|---|
| `empty-no-option-found.png` | `nph-empty`, no option found | light |
| `empty-no-option-found-dark.png` | `nph-empty`, no option found | dark |
